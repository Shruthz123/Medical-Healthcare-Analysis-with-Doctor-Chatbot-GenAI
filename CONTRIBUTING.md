# Contributing to Medical Healthcare Chatbot Starter

Thank you for your interest in contributing to this project! We welcome contributions to help build a secure and helpful healthcare chatbot.

## Proposing Changes
1. **Issues**: Before starting work, please open an issue to discuss the proposed change or feature. This helps us coordinate and avoid duplicate effort.
2. **Pull Requests**: All changes must be submitted via Pull Requests (PRs). 
3. **Review Process**: All PRs require review and approval from a maintainer before they can be merged into the main branch.

## Privacy and Security (CRITICAL)
This project deals with the domain of healthcare. **Strict adherence to privacy standards is required:**
- **No PHI/PII**: Never include real patient data, Protected Health Information (PHI), or Personally Identifiable Information (PII) in issues, pull requests, commit messages, or test data.
- **Mock Data Only**: Use only synthetic, anonymized, or mock data for testing and development purposes.
- **Security**: If you identify a potential security vulnerability, please report it privately rather than opening a public issue.
